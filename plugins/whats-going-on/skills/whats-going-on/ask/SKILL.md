# Ask

Does anyone need something understood, decided, or resolved? Write one note: who asks for what, in their own terms.

- A request for a method (plan, workshop, dashboard, migration) is the ask as said. Do not swap in the question you think is behind it.
- A concern with no request means no ask is stated.
- An FYI or a plain notice with nothing to decide means no ask and nothing to resolve.

"Can we get a dashboard for signups?" notes "Someone asks for a signups dashboard." Not "Someone wants to know why signups fell."

Write only the ask note.
