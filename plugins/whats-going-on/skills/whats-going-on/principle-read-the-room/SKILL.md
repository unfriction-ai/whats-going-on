# Read the room

The next problem is the one the others wait on. A why comes before a how to prevent. Leave every other concern in `unresolved`.

Classify that problem as it stands now. The quadrant names the current reasoning objective.

You skipped this when two problems are both classified, or when the primary is the easiest one to answer instead of the one the others depend on.
