# Do not invent problems

A concern is a problem only when the input states what needs resolving.

Leave missing facts in `unresolved`. Do not add a metric, a cause, or a quadrant the input never gives.

You skipped this when a defined problem uses a number, a timeframe, or a cause the input does not contain.
