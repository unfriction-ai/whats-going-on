# Restate

Write exactly two sentences. Read only the input and the ask note.

1. **The ask.** Who asks for what, in the asker's terms. If the ask note says nothing is asked, write exactly `No ask is stated.`
2. **The situation.** What is going on, in plain words, using only facts in the input. If the input includes a link you could not open, say so here.

The restatement only reports. It names no problem, cause, quadrant, or fix. Do not guess goals or intent. "Probably," "seems to want," and "likely" mean you are guessing. When the input defines no problem, a thin restatement is correct. Filling the gap is invention.
