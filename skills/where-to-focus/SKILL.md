# Where to focus

Run whats-going-on stage `structure-the-problem`.

Entry needs only the main or SMART problem statement. A finished stage-1 status is not required.

1. Read `../whats-going-on/SKILL.md`.
2. Force Select to `structure-the-problem` for this turn.
3. Read `../whats-going-on/playbooks/structure-the-problem.md` and each skill its `skills` list names under `../whats-going-on/`.
4. Follow that playbook's Output and the coordinator Present rules. Stop.

Aliases: `/break-it-down`, `/where-to-start`. Same stage.
